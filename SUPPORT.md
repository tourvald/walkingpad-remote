# Support

Use the GitHub issue forms for normal project support:

- `Bug report` for reproducible failures
- `Feature request` for focused improvement ideas

## Before opening an issue

- Read the main [README](README.md).
- Read [ios/README.md](ios/README.md) if your problem is Xcode, signing, or real-device setup.
- Confirm that the treadmill is not already connected to another app or phone.
- If you are using Python tooling on macOS, confirm that Python has Bluetooth permission.

## Include this context when relevant

- treadmill model
- protocol if known (`WalkingPad`, `FTMS`, or `FitShow`)
- iPhone / iOS version
- Apple Watch / watchOS version
- Xcode version
- Python version
- logs, screenshots, or exported telemetry snippets with sensitive data removed

## Security-sensitive issues

Use [SECURITY.md](SECURITY.md) instead of a normal issue when the report involves a vulnerability, unsafe control path, or sensitive data exposure.
